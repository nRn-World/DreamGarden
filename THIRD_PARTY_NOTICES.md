## Flag artwork

The seven country flags in `public/flags/` are SVG files sourced from
[flagcdn.com](https://flagcdn.com/), which distributes public-domain flag artwork. The flags are
used unmodified, preserve their official proportions and colours, and are never drawn from scratch.
Flags identify the language's associated country; the language name is always shown in its own
script as well.

| File | Country | Source |
| --- | --- | --- |
| `gb.svg` | United Kingdom | `https://flagcdn.com/gb.svg` |
| `se.svg` | Sweden | `https://flagcdn.com/se.svg` |
| `tr.svg` | Türkiye | `https://flagcdn.com/tr.svg` |

## Generated art

All flowers, spirits, decorations, scenery, icons and the feature graphic are original vector art
created for this project. No visual reference from the production brief is copied into the game.

## Audio

There are no audio files. The ambience and interface chimes are synthesized at runtime with the
Web Audio API from original oscillator settings.
